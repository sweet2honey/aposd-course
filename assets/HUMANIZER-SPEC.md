# HUMANIZER-SPEC：课程正文的编辑规则

任务：对这个工作区里的课程 HTML 做一次**编辑**，让中文读起来像人写的，但一个字的事实都不许变。

## 绝对不许动

- `.excerpt` 块里的任何内容 —— 那是书的中文摘译/重述，改了就不再是摘译。
- `<pre>` / `<code>` 里的代码、注释、路径、命令。
- 表格（`<table>` 及其全部单元格）、`.anti .pair` 里的代码侧、`.gloss` 定义、`dt/dd` 结构。
- `.quiz` / `.triage` 的选项文字与 `data-*` 属性：选项字数已刻意相近、正确项位置已打散，改一个字都会破坏设计。
- 标题文字与层级、`<h2>` 里的 `<span class="num">`、crumb、`nav-links`、页脚链接。
- 任何 URL、链接目标、`class`、`id`、文件结构。

只编辑**连续散文段落**：`<p>` 里成句的正文、`<li>` 里的解说句、`<blockquote>` 之外的叙述。

## 要改的问题（按命中率排序）

1. **破折号当万能连接**。全站 604 处「——」，大部分是合法的同位语解释，不要动。只改两类：① 一句话里连用两个以上破折号制造节奏；② 本可以用逗号、冒号或断句的地方硬塞破折号。判断办法：把破折号换成逗号读一遍，如果句子更顺、意思没变，就换。
2. **「不是 X，而是 Y」修辞对比**。全站 60 处。两部分都提供信息、或后半句在纠正真实误解的，保留。纯为抬高语气的（「这不是技巧，而是态度」这类），改成直接陈述。
3. **强调拐杖**：`真正`、`正是`、`恰恰`、`这才是`、`本质上`、`说白了`。全站约 130 处。删掉后句子意思不变的，删。
4. **起跑式铺垫**：`让我们`、`接下来我们`、`下面来看`、`到这里我们已经`。删掉，直接从内容说起。
5. **空泛收尾**：段末重复上一句意思的短句、`仅此而已`、`如此而已`。删。
6. **三连排比凑数**：三个并列项里有一个没有独立信息时，删那一个（不要补造第四项）。
7. **客服腔/自评**：`值得注意`、`有意思的是`、`不得不说`。多数可删。

## 不要做的事

- 不要为了「像人」加口头语、加第一人称经历、加情绪词。作者声音已经定了：直接、克制、承认不确定。
- 不要缩短句子来「显得干净」。长句承载因果链时保留。
- 不要统一句长、不要加小标题、不要重排段落顺序。
- 不要动已经通顺的段落。改动比例低是正常的，改多了是错的。
- 不要把「可能」「通常」「多数情况」改成确定语气；不要把「建议」改成「必须」。
